# Job Hunter - Итоговая конфигурация

## ✅ Реализовано

### Архитектура
- **Бот работает только в личных сообщениях** (никаких групп/каналов)
- **Авторизация по Chat ID** - только вы можете управлять ботом
- **Long polling** - бот опрашивает Telegram API каждые 50 секунд
- **Systemd service** - автозапуск при старте системы

### Команды бота

**`/start`** - показывает справку о доступных командах

**`/update`** - немедленная проверка вакансий
- Проверяет все источники (VK, Yandex)
- Отправляет только **новые** вакансии
- Показывает итоговую статистику
- Защищён блокировкой (если проверка уже идёт)

**`/list`** - показать все известные вакансии
- Показывает **все** вакансии из базы
- Группирует по источникам (VK, Yandex)
- Показывает название, локацию, компанию, ссылку

### Автоматическая проверка

**Cron каждый час** (`/opt/job-hunter/check-vacancies.sh`)
- Запускается в 00:05 каждого часа
- Отправляет уведомления о новых вакансиях
- Использует блокировку (не запустится дважды)

### Уведомления

Все уведомления о новых вакансиях приходят вам в личные сообщения:
- От автоматической проверки (cron)
- От ручной команды `/update`

## 🎯 Использование

1. Откройте чат с ботом **@tabakovsasha_bot**
2. Отправьте `/start` для справки
3. Отправьте `/list` чтобы увидеть все вакансии
4. Отправьте `/update` для немедленной проверки
5. Новые вакансии придут автоматически каждый час

## 🔒 Безопасность

- Только ваш Chat ID может управлять ботом
- Команды от других пользователей игнорируются
- Токен бота хранится в `.env` (не в git)
